# llms.txt

Official proposal: https://llmstxt.org/

llms.txt is a proposed convention for publishing an LLM-oriented overview and curated links at a predictable website path. It is intended to help language-model tools find high-value textual resources.

It is a convention rather than a general authorization or tool protocol. Treat it as discovery/context metadata, not as proof that listed content is trusted or current.
