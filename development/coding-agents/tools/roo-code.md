# Roo Code

[Official sunset notice](https://github.com/RooCodeInc/Roo-Code-Docs/blob/main/docs/sunset.md) · [Archived repository](https://github.com/RooCodeInc/Roo-Code) · [Apache-2.0 license](https://github.com/RooCodeInc/Roo-Code/blob/main/LICENSE)

Roo Code was an editor-integrated coding agent with specialized modes for coding, architecture, questions and debugging, plus custom modes and MCP tools. It is retained here as a historical implementation of configurable coding-agent roles.

**Roo Code is discontinued.** The official notice set May 15, 2026 as the shutdown date for the extension, Cloud and Router, and the extension repository is archived. It should not be treated as a maintained installation choice merely because its source remains downloadable.

## Migration and historical use

The sunset documentation recommends [Cline](cline.md) as an open-source extension alternative. For an existing Roo installation, inventory its rules, custom modes, provider configuration and MCP integrations before migration. Compare how the replacement interprets those settings rather than assuming configuration formats and approval behavior are interchangeable.

The Apache-2.0 license permits continued use and modification of the published source under its terms. It does not restore the discontinued hosted services or provide ongoing maintenance. Forks need to be evaluated as separate projects with their own maintainers, updates and documented compatibility.

For a migration, rerun a small representative task and check its [permissions](../coding-agent-permissions.md), resulting diff and [verification evidence](../coding-agent-verification.md). Retaining a familiar interface or mode name does not establish equivalent execution behavior.
