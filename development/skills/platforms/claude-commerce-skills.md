# Claude commerce skills

Official overview: https://claude.com/solutions/commerce

Anthropic's Claude for commerce materials describe reusable commerce-agent capabilities for consumer and merchant workflows.

Consumer-oriented skills include catalog search and discovery, planning and shopping lists, cart and checkout actions, customer care, and personalization/memory. Merchant-oriented skills include analytics, catalog and inventory management, promotions, campaign management, and personalization/memory.

Anthropic also provides a forkable commerce-agent blueprint and Claude Code plugin. These are implementation resources for building commerce agents with Claude; they are distinct from open commerce protocols such as ACP.

Use this reference when studying **commerce skills as reusable agent behavior**, while keeping catalog APIs, checkout protocols, payments, and merchant systems in the commerce infrastructure taxonomy.
