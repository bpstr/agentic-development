# Anthropic official skills

Official repository: https://github.com/anthropics/skills
Agent Skills specification: https://agentskills.io/specification

Anthropic's public skills repository contains example skills, templates, and the document skills used as reference implementations for Claude's skill system.

The repository includes creative, development, enterprise, communication, and document-oriented examples. Document skills cover formats such as DOCX, PDF, PPTX, and XLSX; licensing differs between parts of the repository, so inspect the relevant files before reuse.

For Claude Code, the repository can also be registered as a plugin marketplace. Anthropic documents installation of its example and document skill bundles through Claude Code's plugin commands.

Use the repository to study real skill organization and progressive loading rather than treating every example as a universal best practice.
