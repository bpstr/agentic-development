# Skill discovery and marketplaces

A skill marketplace or directory indexes reusable agent skills so users and agents can discover installation sources, inspect instructions, and install a skill into compatible clients.

A directory is not the skill specification itself. The portable unit remains the skill package and its `SKILL.md`; discovery services add search, popularity signals, installation commands, and metadata.

When evaluating a marketplace, distinguish:

- canonical source repository;
- publisher identity;
- skill specification compatibility;
- installation mechanism;
- update behavior;
- security scanning;
- popularity signals versus quality evidence.
