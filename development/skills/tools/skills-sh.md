# Skills.sh

Official site: https://skills.sh/
Documentation: https://www.skills.sh/docs

Skills.sh is a public directory and installation surface for agent skills. It exposes skill pages and an `npx skills add` command that can install skills from indexed or directly specified repositories.

Example:

```sh
npx skills add blader/humanizer
```

A Skills.sh listing is a discovery/distribution record, not an endorsement or proof that a skill is safe for a particular environment. Inspect the source `SKILL.md`, bundled scripts, references, assets, permissions, and network behavior before adopting a third-party skill.
