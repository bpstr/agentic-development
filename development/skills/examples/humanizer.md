# Humanizer

Skills.sh: https://skills.sh/blader/humanizer
Canonical repository: https://github.com/blader/humanizer

Humanizer is a widely used writing skill that rewrites AI-shaped prose to reduce repetitive structural and stylistic patterns while preserving meaning.

It is useful as an example of a **pure instruction-oriented skill**: the primary capability comes from reusable written guidance rather than a remote service or agent protocol.

Install through the Skills CLI:

```sh
npx skills add blader/humanizer
```

As with any third-party skill, inspect the current source before installation. Writing transformation is subjective, so evaluate whether its rules preserve domain terminology, authorial voice, quotations, and factual meaning.
