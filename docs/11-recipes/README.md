# 11 · Practical recipes

[Handbook](../../README.md)

These recipes connect the chapters through small application designs. Their data and application APIs are illustrative. The tool-loop repository example is executable offline; the other recipes are implementation guides, not deployed integrations.

| Recipe | Outcome | Verification scope |
| --- | --- | --- |
| [A bounded tool loop](tool-loop.md) | Understand how model output becomes a validated tool execution and result | Offline executable example and behavior tests |
| [Grounded answers](grounded-answers.md) | Answer a question from authorized, identifiable sources | Illustrative architecture and evaluation cases |
| [Background work](background-work.md) | Keep a task running while the client disconnects or continues talking | Illustrative state and event contracts |
| [Build in small increments](incremental-build.md) | Add layers when a concrete need appears | Suggested implementation sequence |

Read the [calling](../03-calling-models/README.md) and [orchestration](../05-orchestration/README.md) chapters alongside the first recipe.
