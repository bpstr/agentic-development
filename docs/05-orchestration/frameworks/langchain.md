# LangChain

[Handbook](../../../README.md) · [Frameworks](README.md)

LangChain provides model/tool integrations and higher-level agent abstractions. Current LangChain agents build on LangGraph, but LangGraph can also be used without LangChain.

Use LangChain when its integrations and agent abstractions remove meaningful application plumbing. Do not treat “using LangChain” as an architecture description: persistence, durable execution, tracing, and deployment still need explicit ownership.

Official documentation: [LangChain overview](https://docs.langchain.com/oss/python/langchain/overview).
