# LangSmith

[Handbook](../../../README.md) · [Frameworks](README.md)

LangSmith provides tracing, evaluation, prompt tooling, and related deployment/platform capabilities. It can be used across frameworks; tracing with LangSmith does not imply LangChain controls execution.

Use it when the observability or evaluation workflow is valuable enough to justify the integration. Diagnose latency with actual spans rather than attributing overhead to an ecosystem name.

Official documentation: [Observability](https://docs.langchain.com/langsmith/observability) · [Evaluation](https://docs.langchain.com/langsmith/evaluation).
