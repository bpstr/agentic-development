# Orchestration frameworks and runtimes

[Handbook](../../../README.md) · [Chapter](../README.md)

Choose a framework by the responsibility it takes over. Provider adapters, agent loops, persistence, observability, managed execution, and UI streaming are different concerns.

## Frameworks

- [LangChain](langchain.md) — integrations and higher-level agent abstractions.
- [LangGraph](langgraph.md) — stateful graph orchestration and persistence.
- [LangSmith](langsmith.md) — tracing, evaluation, and related platform tooling.
- [OpenAI Agents SDK](openai-agents-sdk.md) — application-owned agent runtime utilities.
- [OpenAI Agents API](openai-agents-api.md) — OpenAI-managed agent harness.
- [Vercel AI SDK](vercel-ai-sdk.md) — TypeScript model, tool, agent, and UI integration.
- [Claude Managed Agents](claude-managed-agents.md) — Anthropic-managed agent execution.

A product appearing here does not imply the handbook recommends it. Start with [orchestration fundamentals](../introduction.md), then adopt the smallest layer that solves a measured problem.
