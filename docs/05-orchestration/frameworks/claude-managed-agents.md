# Claude Managed Agents

[Handbook](../../../README.md) · [Frameworks](README.md)

Claude Managed Agents is Anthropic's managed agent execution offering, distinct from direct Messages API inference and from the Claude Code development environment.

Evaluate it as managed execution: inspect sandbox ownership, persistence, retention, tools, interruption behavior, and how application identity reaches side effects.

Official documentation: [Claude Managed Agents overview](https://platform.claude.com/docs/en/managed-agents/overview).
