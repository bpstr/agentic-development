# Vercel AI SDK

Vercel AI SDK is a TypeScript toolkit spanning provider access and application integration. Its core covers model calls, structured output, tools, and agent loops; its UI layer supports streamed application state.

The SDK and Vercel AI Gateway are separate choices. UI hooks do not provide domain authorization, database transactions, or durable job recovery.

Official resources: [repository](https://github.com/vercel/ai) · [documentation map](https://ai-sdk.dev/llms.txt).
