# 02 · Models and providers

[Handbook](../../README.md)

Choose a model for a workload, then choose how to access it. The organization that develops a model, the service that serves its inference, and the platform that runs an agent can be different organizations.

Before selecting, write down required input and output modalities, tool capabilities, task quality, latency, cost, and deployment constraints. A fast text model is not necessarily a suitable voice model; an excellent coding score does not establish reliability at updating business records.
