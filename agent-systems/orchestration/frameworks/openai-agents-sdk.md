# OpenAI Agents SDK

The OpenAI Agents SDK supplies application-owned agent-loop utilities including tools, handoffs, guardrails, sessions, and tracing. The SDK runs with your application; installing it does not deploy your service.

Use it when you want agent abstractions while retaining ownership of application deployment and integrations. Switching between an SDK and direct provider calls changes which orchestration code you own; it does not remove model inference time.

Official documentation: [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/).
