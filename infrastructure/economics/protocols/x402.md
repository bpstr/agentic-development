# x402

Official site: https://www.x402.org/
Specification repository: https://github.com/coinbase/x402

x402 is an open payment protocol built around HTTP 402 Payment Required. A resource server can return machine-readable payment requirements; a client pays according to an advertised scheme and retries the request with payment proof.

This interaction is relevant to agents because paid APIs and resources can become programmatically discoverable and payable without a separate human checkout UI. Treat wallet custody, spending policy, supported networks, settlement, and regulatory requirements as separate concerns from the HTTP protocol itself.
