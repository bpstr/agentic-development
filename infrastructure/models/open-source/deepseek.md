The repository documents MIT terms for its code and weights while separately identifying original Qwen and Llama bases for distilled variants. Check the exact derivative and its upstream conditions rather than transferring one license statement to every artifact.

A distilled model is not the same deployment target as the full model. Record the exact model revision, runtime, quantization, and serving configuration when evaluating it.
