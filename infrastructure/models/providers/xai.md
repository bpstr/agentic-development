# xAI

**Sources reviewed:** 2026-09-19 · **Evidence:** official xAI documentation; no comparative benchmark run.

xAI's Grok model APIs, Grok Build, and Grok Bot belong to different layers.

The [Grok model catalog](https://docs.x.ai/developers/models) is the source for current model IDs and capabilities. The platform distinguishes custom function calls from provider-hosted tools such as web and X search; those tools supply external information and should not be confused with model training knowledge.

**Grok Build** is a coding-agent environment and **Grok Bot** is a persistent work-agent product. They are covered under [coding agents](../../development/coding-agents.md), not treated as language models here.
