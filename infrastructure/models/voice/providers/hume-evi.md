# Hume Empathic Voice Interface

Official documentation: [EVI overview](https://dev.hume.ai/docs/speech-to-speech-evi/overview), [EVI configuration](https://dev.hume.ai/docs/speech-to-speech-evi/configuration/build-a-configuration), [language models](https://dev.hume.ai/docs/speech-to-speech-evi/configuration/language-model), and [Hume Voice](https://dev.hume.ai/docs/voice/overview).

Hume's Empathic Voice Interface (EVI) is a realtime speech-to-speech system designed to use acoustic signals such as rhythm, tone, and vocal modulation as part of conversation handling. Hume documents native speech-language models for EVI and configurable voice output.

The current documentation distinguishes EVI versions including EVI 3 and EVI 4-mini, while Hume's Voice product documents Octave speech-language models for expressive synthesis and voice design. Version availability, supported languages, and preview status should be checked before deployment.

EVI configuration can include the voice, system prompt, and language-model selection. These settings affect conversational behavior but do not replace application permissions, tool validation, or durable task state.

Hume is useful to evaluate when prosody and affective acoustic information are part of the product requirement rather than incidental presentation. Test those benefits on the target language, microphone conditions, interruptions, and domain tasks instead of assuming an emotion-aware model improves every voice workflow.
