# OpenAI GPT Image

Official documentation: https://developers.openai.com/api/docs/guides/image-generation

OpenAI's GPT Image family provides image generation and editing from text and image inputs. Current model documentation separates faster everyday generation from higher-precision editing-oriented models.

The image API supports generation and editing workflows. GPT Image models can also be used through supported model/tool surfaces, so applications should distinguish a direct image-generation request from an agent choosing an image-generation tool.

Use GPT Image for text-to-image generation, image editing, iterative visual workflows, and image-conditioned generation. Pin model snapshots when reproducibility matters and validate output dimensions, transparency, quality settings, moderation behavior, and cost against the current model documentation.
