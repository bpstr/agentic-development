# Google Veo

Veo is Google's video-generation model family. It belongs under video generation rather than general Gemini model inference because its primary output is generated video.

Use Veo for text-conditioned and supported image-conditioned video generation. Evaluate the exact model/version for duration, resolution, audio capabilities, prompt adherence, temporal consistency, generation latency, and availability through the Google surface you plan to deploy.

Prefer Google's current model and API documentation when recording specific limits because Veo versions and supported generation controls change over time.
