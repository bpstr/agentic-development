# Seedance

Seedance is ByteDance's video-generation model family for generative video workflows. It belongs in the video-generator taxonomy rather than under general-purpose language models.

Use the exact provider documentation for the deployed Seedance version when recording supported text/image conditioning, duration, resolution, audio, camera controls, pricing, and regional availability. These capabilities vary between releases and serving platforms.

Evaluate Seedance on temporal consistency, subject preservation, motion quality, prompt adherence, and end-to-end generation latency rather than judging isolated frames.
