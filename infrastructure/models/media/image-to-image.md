# Image-to-image generation

Image-to-image generation conditions output on one or more input images. Common operations include localized editing, inpainting, outpainting, background replacement, style transfer, compositing, variation generation, and iterative refinement.

The key evaluation property is **preservation under change**: requested regions or attributes should change while unrelated details remain stable. Reference fidelity, mask behavior, multi-image conditioning, transparency, and repeated-edit consistency are important production concerns.
