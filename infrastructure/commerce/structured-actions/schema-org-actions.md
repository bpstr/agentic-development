# Schema.org Actions

Official documentation: https://schema.org/Action

Schema.org Actions model potential or completed actions as structured data. An Action can describe an operation, its participants, objects, targets, status, and expected inputs or outputs.

Actions predate modern LLM agents, but they are relevant to agentic systems because they demonstrate a web-native vocabulary for describing executable or invokable capabilities in structured data.

Schema.org Actions are not equivalent to MCP, WebMCP, or an agentic checkout protocol. They describe semantic action data; they do not by themselves define an agent runtime, transport, authorization model, or execution lifecycle.

Use them when interoperable structured web semantics are useful, particularly when an existing Schema.org vocabulary already describes the domain action.
