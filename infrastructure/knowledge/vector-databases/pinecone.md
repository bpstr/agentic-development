# Pinecone

Official resources: [Quickstart](https://docs.pinecone.io/guides/get-started/quickstart), [Upsert records](https://docs.pinecone.io/guides/index-data/upsert-data), [Semantic search](https://docs.pinecone.io/guides/search/semantic-search).

Pinecone is a managed retrieval service with vector indexes, namespaces, metadata, and supported integrated-inference workflows. It is useful when an application wants managed search infrastructure rather than operating the underlying vector service.

Choose whether the index receives vectors generated by your application or text handled by a supported integrated embedding model. These have different ingestion and search interfaces; do not combine examples from the two workflows.

For a bring-your-own-vector index, create an index with the required dimension and metric, then install `pinecone` and supply its API key and index host through environment variables. This example requires an existing three-dimensional demonstration index:

```python
import os
from pinecone import Pinecone

pc = Pinecone(api_key=os.environ["PINECONE_API_KEY"])
index = pc.Index(host=os.environ["PINECONE_INDEX_HOST"])
index.upsert(
    namespace="workspace-7",
    vectors=[{
        "id": "rollback-1",
        "values": [1.0, 0.0, 0.0],
        "metadata": {"source_id": "runbook-billing", "revision": "12"},
    }],
)
print(index.query(
    namespace="workspace-7",
    vector=[0.9, 0.1, 0.0],
    top_k=3,
    include_metadata=True,
))
```

Artificial vectors demonstrate the storage/query contract. Select the namespace server-side from authenticated scope and preserve source text separately when it is not stored in metadata. Confirm write visibility before asserting immediate read-after-write behavior.

This is a documented API example, not an executed service test; running it uses the configured hosted account. Size, regions, limits, and pricing should be checked in Pinecone's current documentation for the intended deployment.
