# Cognee

Cognee is a knowledge infrastructure framework that turns data into graph- and vector-backed representations for retrieval and agent memory. It combines ingestion, transformation, graph construction, embeddings, and retrieval behind a higher-level data pipeline.

Within GraphRAG, Cognee is useful as an implementation that can extract entities and relationships and make those structures available alongside semantic retrieval. It should not be treated as the definition of GraphRAG itself: graph construction quality, source provenance, permissions, freshness, and retrieval strategy remain application concerns.

Cognee also overlaps with agent memory, so it can legitimately appear from the memory perspective as the taxonomy expands.

Official resources: [Cognee documentation](https://docs.cognee.ai/) · [Cognee repository](https://github.com/topoteretes/cognee).
