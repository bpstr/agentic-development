# Vercel AI SDK UI

AI SDK UI is the interface layer of Vercel's AI SDK. It provides framework integrations for building conversational and generative interfaces around streamed model and agent state.

Its role is application UI state and transport integration, not durable orchestration or domain authorization. An application can use AI SDK UI while executing agents through a different backend architecture.

Official documentation: [AI SDK UI](https://ai-sdk.dev/docs/ai-sdk-ui/overview).
